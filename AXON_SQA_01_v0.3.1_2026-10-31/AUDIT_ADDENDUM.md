# v0.3.1 감사 보완서

작성일: 2026-10-31 KST. 소프트웨어 기준선 통과는 확인되었으며, 새 로컬 M3·YourOS 보고는 원시 근거 접수 전이다.

## 승인 문구

> AXON-SQA-01 v0.3은 배포 무결성과 제한된 소프트웨어 기능검증을 통과했다. 로컬 M3·YourOS의 별도 검증 결과가 보고되었으며, 원시 근거의 독립 재현과 타이밍·전력·극저온·종단 간 QEC 검증은 후속 게이트로 관리한다. v0.3.1은 이 경계를 문서와 검사 절차에 반영한다.

FULL PASS를 사용한다면 반드시 ‘배포 무결성 및 명시된 Python 기능시험 범위’를 병기한다. 모든 설계 선택의 실현 가능성 승인으로 사용하지 않는다. 시험 통과는 모든 버그 부재나 물리 모델의 완전성을 증명하지 않는다.

## 분석과 실측 용어

- Yosys cells/LUT/DSP/LTP: 특정 합성 실행의 구조 통계 `[SYNTHESIZED]`.
- STA·배치/배선 후 timing: 명시된 PVT·라이브러리·배선·제약의 **타이밍 분석값**. 보드 실측으로 부르지 않는다.
- FPGA/실리콘 계측: 계측기·해상도·조건·표본 수가 연결된 `[FPGA-MEASURED]` 또는 `[SILICON-MEASURED]`.
- 4K·77K 동작: 해당 부품·온도의 기능·전력·시간 시험이 별도로 필요하다.

‘구리선 전도열 격리’도 광으로 대체한 특정 신호 배선의 부하 감소로 범위를 좁힌다. 전원 배선·지지구조·광흡수·복사를 포함한 총 열부하 제거를 뜻하지 않는다.

## 거부 예제와 신규 자료

claims_m3_unverified.json은 기존 미검증 주장 fixture다. 그 거부 성공은 새 M3 자료를 심사한 결과가 아니다. m3_intake_template_check.json 역시 빈 서식의 거부 결과다. 실제 제출은 별도 폴더·실제 SHA·계약·원시 파일로 한다.

파일 존재와 해시 일치는 진위·로그 의미·동치 인증이 아니다. 접수기는 사람이 검토할 근거의 완결성을 확인한다. 실제 기능·거리·교정 범위·합성 통계 원문은 후속 검토·재현 대상이다.

## 배포와 실행 분리

v0.3은 실행 시 results 로그와 시각이 갱신되어 원본 manifest와 달라질 수 있었다. v0.3.1은 runs/latest에 출력하고 source manifest를 먼저 검사한다. 배포 results는 보존한다. verify_release는 manifest를 재생성하지 않는다.

**수정 문구:** 배포·소프트웨어 시험 통과와 원본 M3 로컬 검증 보고를 구별해 기록했다.

**누락 근거:** 코드별 full SHA·계약·Rust/RTL 대조·합성 run 연결, YourOS 원본·CI 로그, CAD·규격 원본.

**최소 다음 실험:** 같은 코드·입출력·측정모델에서 Rust↔RTL 대조 후 통계별 top·target·script·log를 묶는다. 정확도가 맞은 뒤 시간·전력을 비교한다.
