# AXON Photonic QPU P1 — 연구용 기준선 v0.2

## v0.2 추가: HOM 검출 실험 모델

`experiment.py`는 균형 빔스플리터와 입력당 단일 광자 1개를 가정하고 광자 구별가능성의 가우시안 지연 모델, 경로별 독립 효율, 검출기 암계수, 임계값 검출기의 두 광자 포화 및 동시 클릭을 계산한다. `run_experiment.py`는 임의 단위 지연과 가정값을 사용해 고정 시드의 반복 검출 횟수를 JSON으로 출력한다. `python -m unittest -v` 로 14개 시험, `python run_experiment.py` 로 예제를 실행한다.

예제의 가시도 0.9, 효율 0.70/0.65, 암계수 0.001은 임의 가정이다. 지연 0에서 기대 동시 클릭 확률 약 0.02362, 큰 지연 4에서 약 0.22810은 이 가정에 따른 시뮬레이션으로 PAT-34/35/36 소자나 77K 성능과 무관하다. `visibility`는 광자 중첩도 최대값이며 검출 암계수 등을 포함한 측정 가시도와 일반적으로 다르다. 암계수는 시간 게이트당 확률이고, 출력 JSON의 지연 값은 물리 단위가 아니다.

모델은 광자원 실패·다중 광자·잡음 광자·검출기 후발펄스·데드타임·상관 손실·온도·주파수·양자상태 자체·실험의 통계적 불확도·QEC를 다루지 않는다. 광학 빔스플리터와 반사 캡의 실제 결합 구현은 확인되지 않았다. 고전 광원의 빛이 양자 수신기에 새어 들어가는 현상은 이 모델에 포함되지 않는다.

다음 단계는 실제 광원·검출기의 데이터시트와 광로 손실을 수집하여 입력을 측정값으로 교체하고 원시 클릭·동시계수 및 불확도를 대조하는 것이다. 데이터가 없으면 파라미터 연구로 유지한다.

상태: [SIMULATED] / 설계 제안. 원본 PAT-36 미확보. PAT-35 Rev.B 그림을 참조한 독립 추가물이며 원본 수정이나 반도체·양자장치 완성이 아니다.

## 구성과 경계

고전 경로: AXON OS/CPNPU → 광 송신 → PAT-35 자유공간 반사 캡 → 차동 PD/TIA/ADC → 고전 제어·계측. 77K 사용 가능성은 부품 실측 대상.

양자 경로(제안): 단일광자원 → 듀얼레일 상태 준비(두 광모드) → 위상기/빔스플리터 → 양자 간섭·측정 → 단일광자 검출기 → 고전 판독. 고전 강광과 양자 광자는 별도 경로로 우선 운영. 누광, Raman 잡음, 편광, 검출기 손상, 열부하를 측정해 공유 가능성을 판단. 일반적인 InGaAs 차동 PD는 단일광자 검출기라고 가정하지 않는다. 검출기 온도는 실제 제품별로 지정한다.

인코딩: |0L>=|10>, |1L>=|01>. 광원 성능, 손실·누화, 위상 안정성, 광자 구별불가능도, 검출 특성은 전부 미측정. 77K 광제어와 QPU 온도는 별도 사양. 광자 비행시간과 유효 측정·피드백 전체 지연은 분리한다.

## P0 구현

`photonic.py`는 단일 광자 두 모드의 이상적 빔스플리터와 위상 변환, 이상화된 HOM 동시검출 확률, 독립 효율 곱만 계산한다. 실제 금 반사 캡, 파장, 다중광자 방출, 검출기 잡음, 냉각, 캘리브레이션, QEC, 2큐비트 게이트, 5큐비트 회로를 모델링하지 않는다. P0의 두 광모드와 광 캐비티 연결은 개념적이며 정확한 광학 소자 설계가 아니다.

실행: `python -m unittest -v` (표준 라이브러리만 사용).

50:50 HOM 대조는 구별 불가능 광자에서 동시검출 확률 0, 완전히 구별 가능한 광자에서 0.5를 예측한다. 이 값은 이상적 이론값이며 장치 성능이 아니다. 손실 계산은 각 효율이 독립이라는 가정하의 곱이며 실제 시스템 성공률이 아니다.

## 개발 단계와 게이트

1. 원본 PAT-36·PAT-35 CAD/회로/RTL·BOM·측정 기록을 확보해 입출력과 실측 범위를 확정한다. 기존 설계가 광자 QPU를 포함하는지 확인한다.
2. 실물 광학 PoC는 강광 고전경로의 손실·반사율·온도 반복 내구성·잡음·누광부터 측정한다. 레이저와 극저온 장비는 전문 시설·절차를 적용한다.
3. 광자 경로에서 단일광자원과 검출기를 독립 검증하고 듀얼레일 간섭계를 시험한다. 위상 변조에 따른 검출 확률, 손실, 효율, 암계수, 신호 대 잡음을 함께 기록한다.
4. 독립 광자 2개의 HOM 간섭을 지연시간 스캔으로 계측한다. 우연 동시계수·다중광자·검출기 효율·불확도를 포함하여 보정 전후 결과를 기록한다.
5. 실제 채택한 광자 얽힘/퓨전 프로토콜에 대해 회로, 보조 광자, 검출 패턴, 성공 표시, 조건부 충실도와 무조건부 성공률·손실을 명시한다. 이 패키지는 이 게이트를 구현하지 않는다.
6. 그 다음 5큐비트 부호의 상태 준비·반복 신드롬·광손실·보조 자원·피드포워드·논리 오류율을 검증한다. 표준 5큐비트 코드 사이 단순 비트별 transversal CNOT은 코드 공간을 보존하지 않는다. 50~10000 큐비트 확장은 목표이며 실증이 아니다.

## 광자 수·자원 계약

5 데이터 큐비트의 듀얼레일은 10개 광학 모드다. 이상적 순간의 부호화된 데이터에는 광자 5개가 있으나, 실제 상태 준비·얽힘·측정에는 보조 광자/모드/검출기·재시도·스위치 등이 추가된다. 광자의 이동성과 수명 때문에 시간 슬롯·동기화·대기 방식을 명시하기 전 메모리처럼 지속 보관된다고 가정하지 않는다. 규모별 물리 큐비트와 논리 큐비트, 성공 확률과 처리율을 별도로 집계한다.
